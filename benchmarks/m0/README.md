# M0 benchmark

Run `arca-m0 --json benchmark-results.json` after installing the package. The suite is deterministic and generated in code: 30 Horn-rule queries, 35 A* grids and 35 safe arithmetic expressions.

A real baseline suite will pin exact model artifacts, inference engines and checksums. ARCA does not label hand-written heuristics as a “0.5B neural baseline.”
